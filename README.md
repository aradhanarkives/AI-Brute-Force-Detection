# 🛡️ Adaptive Identity-Aware Brute Force Detection Using Three-Memory Trust Intelligence

### An AI-Powered Cybersecurity Project

## 📌 About the Project

This project aims to detect brute-force login attacks using machine learning, identity-aware analysis, adaptive trust scoring, and a unique Three-Memory Trust Intelligence approach.

It analyzes login behavior, identifies suspicious activity, and uses stored security history to support more informed risk decisions.

## 🎯 Objectives

- Detect suspicious login attempts and potential brute-force attacks.
- Analyze login behavior using machine learning.
- Identify unusual activity through anomaly detection.
- Maintain three types of security memory for risk analysis.
- Improve threat detection through adaptive trust scoring.

## 🧠 Three-Memory Trust Intelligence

**1. Identity Memory**  
Stores login history and identity-related behavioral information to help identify suspicious changes.

**2. Attack Pattern Memory**  
Records suspicious login patterns to support the recognition of recurring attack behavior.

**3. Decision Recovery Memory**  
Stores previous security decisions and related information to support future risk assessments.

## 🏗️ System Workflow

1. Collect and preprocess login data.
2. Extract relevant login behavior features.
3. Analyze activity using machine learning models.
4. Evaluate unusual patterns and identity history.
5. Consult the three memory components.
6. Generate a risk assessment and flag suspicious activity.
